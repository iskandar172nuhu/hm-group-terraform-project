# ALB Module

## Purpose

This module provisions Application Load Balancers for the HM Group 3-tier AWS infrastructure.

## Resources Created

- Public Application Load Balancer
- Internal Application Load Balancer
- Web target group
- App target group
- HTTP listeners
- Health checks

## Key Features

- Internet-facing load balancing for the web tier
- Internal load balancing for the application tier
- Target group health checks
- High availability across multiple subnets
