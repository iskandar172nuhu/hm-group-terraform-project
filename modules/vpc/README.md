# VPC Module

## Purpose

This module provisions the networking foundation for the HM Group 3-tier AWS infrastructure.

## Resources Created

- VPC
- Public subnets
- Private application subnets
- Private database subnets
- Internet Gateway
- NAT Gateway
- Route tables
- Route table associations

## Key Features

- Multi-AZ network design
- Public and private subnet segmentation
- Secure database subnet isolation
- Controlled outbound access through NAT Gateway
