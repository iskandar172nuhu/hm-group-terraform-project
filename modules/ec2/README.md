# EC2 Module

## Purpose

This module provisions EC2 Launch Templates and Auto Scaling Groups for the HM Group infrastructure.

## Resources Created

- Web tier launch template
- App tier launch template
- Web Auto Scaling Group
- App Auto Scaling Group

## Key Features

- Auto Scaling for high availability
- Launch template-based deployments
- Dynamic EC2 provisioning
- Integration with Application Load Balancers
- Multi-AZ deployment support
